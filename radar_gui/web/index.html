Subframe: default -1 = all subframes (0 in cfgs without advFrameCfg).
HSI header: default off; when on, a header is prepended to each chirp's LVDS data.
HW stream: shipped LVDS cfgs use 1 (ADC data); 0 = off, 4 = CP ADC + chirp quality, 2 = ADC + metadata (SAR firmware only). Only values the selected firmware accepts are offered.
SW stream: default off; the software session always sends the HSI header, so the header must be on whenever both streams are on.
